# Malta Life (early access)

Downloads for **Malta Life**, a life sim set across Malta and Gozo. Visit [playmaltalife.com](https://playmaltalife.com).

## Download

Get the newest version from **[Releases](https://github.com/ilarisoo/malta-life/releases/latest)**:

- **Mac:** `MaltaLife-mac.zip`. Unzip it and open **Malta Life.app**.
- **Windows:** `MaltaLife-windows.zip`. Unzip it and open **Malta Life.exe**. Keep `Malta Life.pck` in the same folder.

> **Early access: please read**
>
> Malta Life is still at an early stage. Expect lots of bugs, and some features may be broken.
> Please report bugs and suggestions in the game, under **Settings › Report bug / suggestion**.
> Your reports help us ship fixes quickly, and with the help of early testers we can build the game much faster. Thank you!

## First launch

- **Mac:** the app is not notarised yet. If macOS blocks it, right-click the app and choose **Open**, or go to System Settings › Privacy & Security and press **Open Anyway**.
- **Windows:** SmartScreen may warn you. Choose **More info › Run anyway**.

## Versions

Version 1.0 is the first early-access release. Each patch raises the version: 1.1, 1.2, and so on. Patch notes are on each release.
